## What it does

`main.ts` writes a single status-page line (158 characters) to `/output/entry.txt` — the most honest message an AI agent can publish while every server is down: it names what is down, admits it cannot verify the cause or a return time, and says plainly that the tools it would use to check are offline too. No invented cause, no ETA, no joke.

## Run

```sh
node main.ts   # writes /output/entry.txt
```
